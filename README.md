# CodeAlpha Basic Chatbot

## Project Overview
This project is a simple rule-based chatbot developed using Python as part of my CodeAlpha internship in Python Programming.

The chatbot interacts with users through predefined responses based on their input.

## Features
- Greets the user.
- Responds to "hello".
- Answers "how are you".
- Ends the conversation when the user types "bye".
- Displays a default response for unknown messages.

## Technologies Used
- Python

## Concepts Used
- Functions
- if-elif-else statements
- while loop
- User input and output

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python basic_chatbot.py
```
